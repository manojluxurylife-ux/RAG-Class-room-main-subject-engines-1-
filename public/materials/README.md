Drop study material files (PDF, JPG, PNG, MP4) anywhere under this folder.
Subfolders are optional — used only as the `subfolder` query param in
/api/admin/vps for organising the admin browser, e.g.:

  public/materials/maths/class8/chapter-3-algebra.pdf
  public/materials/science/class6/photosynthesis.pdf

Files here are served as static assets by Next.js/nginx automatically —
no upload code needed for VPS-sourced materials.
